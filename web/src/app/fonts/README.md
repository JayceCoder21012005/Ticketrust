# Be Vietnam Pro (self-hosted)

- Family: Be Vietnam Pro, Copyright 2021 The Be Vietnam Pro Project Authors (https://github.com/bettergui/BeVietnamPro).
- Source: Google Fonts (`https://fonts.googleapis.com/css2?family=Be+Vietnam+Pro:wght@400;500;600;700`, woff2 files from
  `fonts.gstatic.com/s/bevietnampro/v12/`), retrieved 2026-11-04 with a Chrome user agent so woff2 is served.
- Files: weights 400, 500, 600, 700, subsets `latin` and `vietnamese` (the `latin-ext` subset is not used), unmodified.
  `../fonts.css` declares them with the same `unicode-range` Google serves.
- Licence: SIL Open Font License 1.1. The notice is in [`../../../assets/fonts/OFL.txt`](../../../assets/fonts/OFL.txt)
  (that directory also holds the Bold TTF used for the OpenGraph image).
